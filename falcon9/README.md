# falcon9

獵鷹九號 3D 發射與第一節回收遊戲。手動飛過最大動壓、看一二級分離運鏡，再把第一節推進器垂直降落在海上無人船的甲板中央。

- 網址：https://joehou45.github.io/falcon9/
- Three.js 3D 場景：發射台、海岸、海面、雲層、會展開著陸腳的火箭模型、無人船
- 上升段要降油門通過 Max-Q、跟著目標俯仰做重力轉彎；回收段看預測落點與著陸燃燒指示器
- 三種難度（側風、燃料、甲板寬度、湧浪），S／A／B／C 評級，自動降落示範
- 鍵盤、觸控按鈕都能玩；用 HTTPS 開啟時可啟用 iPhone 陀螺儀轉向
- 不需要登入，最佳分數只存在玩家自己的瀏覽器

物理與數字經過遊戲化調整，不是 SpaceX 的真實飛行資料。
